MiddleWares:-
   MiddleWares are act as Intermediate B/w the Request and ResPonse


   MiddleWare also Send the response But Usally MiddleWare are not used for Response
     Middleware is used to process requests before they reach the final route handler

 In ExPress The MiddleWares are Come to Play after Server Receives that Request and Before the ResPonse 
  is Sent to the Client

  * method-override 
  * express.static
  * express.urlencoded
  * bodyParser     
  -> These are MiddleWares used in Express

  Using Next() :-
      next()
       Will be used When if the One-MiddleWare Fails Then it Passes to Next-MiddleWare
        next is an Simply it is End of an MiddleWare

        app.use((req,res)=>{
            console.log("This is My-First MiddleWare");
            res.send("Hi, I am MiddleWare");
        })                                          --> this is a MiddleWare But it Send Response but MiddleWare are Not Used for this
                                                        So We use next();   

      app.use((req,res,next)=>{
            console.log("This is My-First MiddleWare");
            next();                        --> next() will execute Routes if not Error in Middleware,
                                               is used to pass control to the next middleware function or route handler
        })

     ERROR'S :-
   ------------
    NormalError  -> Bydefault Express Will Thorw an Error
    tryCatch     -> All Route i.e CURD Route are Placed Inside the try{} and Catch() Block
    AsyncWrap    -> AsyncWrap Means Create a Fuction-method Called AsyncWrap and Inside the AsyncWrap we will Pass the Error

      Syntax :-
        function AsyncWrap(fn){
            return function(err,req,res,next){
                fn(err,req,res,next).catch((err)=>{
                    next(err);
                })
            }
        } 

        // CREATE operation
            app.post("/create", AsyncWrap((req, res) => {
                let { name, age } = req.body;

                res.send(`User Created: ${name}, Age: ${age}`);
            }));

                         

    // try-Catch
